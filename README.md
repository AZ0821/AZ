# 汉UI HanUI

**中文命令驱动的开源 RPA 桌面工具**（对标 TagUI）。

用中文写自动化脚本，底层由 [Playwright](https://playwright.dev) 驱动浏览器：

```
打开 https://www.baidu.com
输入 "#kw" 为 "汉UI 自动化"
点击 "#su"
等待 2 秒
读取 "#content_left" 到 结果
打印 结果
截图 "搜索结果.png"
```

## 特性

- **中文命令 DSL** —— 不用写英文关键字，命令即文档
- **网页自动化优先** —— Playwright 驱动，支持 Chromium / Firefox / WebKit
- **智能元素定位** —— CSS / XPath / 文本 / 中文 `文本=` 前缀，裸中文自动按文本找
- **桌面 GUI** —— 语法高亮编辑器 + 实时日志 + 一键运行
- **命令行** —— `hanui run 脚本.hrpa`，便于集成到 CI / 调度
- **变量与断言** —— 读取页面内容存变量、断言校验，失败即报错退出
- **Apache 2.0 开源** —— 可自由商用、修改、分发

## 安装

```bash
# 1. 安装依赖（Python 3.10+）
pip install -e .

# 2. 安装浏览器内核
python -m playwright install chromium
```

## 使用

### 命令行

```bash
# 运行脚本（默认无头模式）
hanui run examples/百度搜索.hrpa

# 显示浏览器窗口
hanui run examples/百度搜索.hrpa --show

# 慢速模式（每步间隔 200ms，便于观察）
hanui run examples/百度搜索.hrpa --show --slow 200

# 仅解析，不执行（调试脚本）
hanui parse examples/百度搜索.hrpa

# 打开图形界面
hanui gui
```

### 录制操作

录制器会打开可见浏览器，你在页面上的每一次操作都会被翻译成中文命令：

```bash
# 开始录制（关闭浏览器或 Ctrl+C 结束）
hanui record

# 指定起始网址并保存到文件
hanui record --start https://www.baidu.com -o 我的脚本.hrpa
```

录制过程中，每一步都会实时打印：

`
· 打开起始页 https://www.baidu.com
» 打开 https://www.baidu.com
» 输入 "#kw" 为 "汉UI"
» 点击 "#su"
`

**录制器捕获的操作：**

| 用户操作 | 生成命令 |
|---------|---------|
| 点击按钮/链接 | 点击 "选择器" 或 点击 文本=登录 |
| 在输入框打字 | 输入 "#kw" 为 "搜索词"（自动合并连续输入） |
| 选择下拉框 | 选择 "#city" 选中 "北京" |
| 双击 | 双击 "#item" |
| 右键 | 右击 "#menu" |
| 页面跳转 | 打开 https://... |
| 上传文件 | 上传 "#file" 文件 "<请选择文件>" |

**选择器自动生成优先级：**
1. 唯一 #id
2. data-testid / data-test / data-qa
3. 唯一 [name="..."]
4. placeholder / ria-label
5. 按钮/链接的可见短文本 → 文本=登录
6. CSS 路径兜底

在 GUI 里按 **Ctrl+R** 也可以开始录制，录制结果直接写入编辑器。

### 元素操作

| 命令 | 说明 | 示例 |
|------|------|------|
| `点击 <目标>` | 单击 | `点击 "#submit"` |
| `双击 <目标>` | 双击 | `双击 "#item"` |
| `右击 <目标>` | 右键菜单 | `右击 "#menu"` |
| `悬停 <目标>` | 鼠标悬停 | `悬停 ".dropdown"` |

| `清空 <目标>` | 清除内容 | `清空 "#kw"` |
| `选择 <目标> 选中 <值>` | 下拉框选中 | `选择 "#city" 选中 北京` |

| `向上滚动 [像素]` | 页面上滚 | `向上滚动 300` |

### 读取与变量

| 命令 | 说明 | 示例 |
|------|------|------|
| `读取 <目标> 到 <变量>` | 取文本 | `读取 "h1" 到 标题` |
| `读取属性 <目标> 的 <属性> 到 <变量>` | 取属性 | `读取属性 "#a" 的 href 到 链接` |

| `{变量}` | 在任意文本中插值 | `输入 "#u" 为 "{姓名}"` |

### 等待

| 命令 | 说明 | 示例 |
|------|------|------|
| `等待 <N> 秒` / `毫秒` | 固定等待 | `等待 2 秒` |
| `等待元素 <目标>` | 等元素可见 | `等待元素 "#done"` |
| `等待文本 <文本>` | 等文本出现 | `等待文本 "加载完成"` |

### 断言

| 命令 | 说明 | 示例 |
|------|------|------|
| `断言 页面包含 <文本>` | 页面含文本 | `断言 页面包含 欢迎` |
| `断言 页面不包含 <文本>` | 页面不含 | `断言 页面不包含 错误` |
| `断言 元素 <目标> 存在` | 元素存在 | `断言 元素 "#ok" 存在` |
| `断言 元素 <目标> 不存在` | 元素不存在 | `断言 元素 ".error" 不存在` |
| `断言 标题为 <文本>` | 标题精确 | `断言 标题为 "首页"` |
| `断言 标题包含 <文本>` | 标题含 | `断言 标题包含 首页` |
| `断言 网址包含 <文本>` | URL 含 | `断言 网址包含 /login` |

| `截图 [文件名]` | 整页截图 | `截图 "结果.png"` |

### 流程控制

`
# 条件分支
如果 页面包含 欢迎
  点击 "#continue"
否则
  点击 "#retry"
结束

# 循环（当条件成立时重复）
当 元素存在 "#loading"
  等待 1 秒
结束

# 固定次数循环（{循环次数} 是内置计数变量）
重复 3 次
  截图 "第{循环次数}次.png"
结束

# 嵌套
如果 变量 状态 = 成功
  重复 2 次
    打印 第 {i} 遍
  结束
结束
`

**条件写法：**

| 条件 | 说明 |
|------|------|
| 页面包含 <文本> / 页面不包含 <文本> | 页面 HTML 是否包含 |
| 元素 <目标> 存在 / 不存在 | 元素是否存在 |
| 标题为 <文本> / 标题包含 <文本> | 页面标题 |
| 网址包含 <文本> | URL 包含 |
| 变量 <名> = <值> | 变量相等 |
| 变量 <名> != <值> | 变量不等 |
| 变量 <名> 包含 <值> | 变量包含 |
| 真 / 假 | 恒真 / 恒假 |

**循环内置变量：**

| 变量 | 说明 |
|------|------|
| {循环次数} / {i} | 当前是第几轮（从 1 开始） |

### 元素定位方式

| 写法 | 含义 |
|------|------|
| `"#id"` `".class"` `"div > p"` | CSS 选择器 |
| `"/html/body/..."` | XPath |
| `"登录"` `登录` | 文本定位（含中文或普通短语） |
| `文本=登录` / `text=Login` | 显式文本定位 |
| `css=...` `xpath=...` `id=...` `name=...` | 显式前缀 |
| `h1` `input` `button` | HTML 标签名 → CSS 标签选择器 |

## 打包

### 本地打包

**Windows:**
```powershell
.\build.ps1
```

**macOS / Linux:**
```bash
bash build.sh
```

自动产出：zip 分发包 + .sha256 校验文件。

### CI 自动打包（三平台）

推送 * 标签后，GitHub Actions 自动打包 Windows / macOS / Linux：

```bash
git tag v0.1.0
git push origin v0.1.0
```

也可在 Actions 页面手动触发（workflow_dispatch）。

产物：
| 平台 | 文件名 |
|------|--------|
| Windows | hanui-v0.1.0-win64.zip |
| macOS (Apple Silicon) | hanui-v0.1.0-macos-arm64.zip |
| Linux x64 | hanui-v0.1.0-linux-x64.zip |

Release 页面附带 .sha256 校验文件。

### Windows 打包为 exe

让没装 Python 的人也能用：

```bash
# 一键打包
.\build.ps1

# 或手动
python -m PyInstaller hanui.spec --noconfirm
```

产物在 `dist/hanui/`：

| 文件 | 说明 |
|------|------|
| `hanui.exe` | 主程序（双击打开 GUI） |
| `examples/` | 示例脚本 |
| `安装文件关联.bat` | 双击运行后 .hrpa 可直接双击运行 |

### 分发给他人

1. 把 `dist/hanui` 整个文件夹发给对方
2. 对方双击 `安装文件关联.bat`（仅需一次，自动识别路径）
3. 之后双击任意 `.hrpa` 文件即可运行

### 双击 .hrpa 文件时

- 弹出运行进度窗口
- 自动显示浏览器并执行脚本
- 实时日志 + 成功/失败提示

### 浏览器说明

打包后的 exe **不内置浏览器内核**（体积小 ~150MB）。运行时按以下顺序自动探测：

1. 系统 Microsoft Edge（Win10/11 自带）
2. 系统 Google Chrome
3. Playwright 内置 Chromium（如果已下载）

如需强制指定，命令行加 `--browser msedge` 或 `--browser chrome`。
