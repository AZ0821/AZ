# 汉UI 使用说明

**中文命令驱动的自动化工具** —— 用中文写脚本，自动操作浏览器。

## 快速开始（3 步）

### 第 1 步：解压

把压缩包解压到任意目录。

### 第 2 步：安装文件关联

双击 **`安装文件关联.bat`**，按提示完成。

这一步只需做一次。完成后，`.hrpa` 脚本文件就能直接双击运行了。

### 第 3 步：运行示例

双击 `examples` 文件夹里的 **`表单示例.hrpa`**，看效果。

## 日常使用

| 操作 | 方法 |
|------|------|
| **运行脚本** | 双击 `.hrpa` 文件 |
| **写新脚本** | 双击 `hanui.exe` 打开编辑器 |
| **录制操作** | 打开编辑器后按 `Ctrl+R`，在浏览器里操作，完成后点「停止录制」 |

## 脚本怎么写？

用**中文命令**一行一条，例如：

```
打开 https://www.baidu.com
输入 "#kw" 为 "天气"
点击 "#su"
等待 2 秒
截图 "搜索结果.png"
```

### 常用命令速查

| 想做什么 | 写什么 |
|---------|--------|
| 打开网页 | `打开 https://xxx.com` |
| 点击按钮 | `点击 "登录"` 或 `点击 "#submit"` |
| 输入文字 | `输入 "#username" 为 "张三"` |
| 等一会儿 | `等待 2 秒` |
| 截图保存 | `截图 "结果.png"` |
| 读取网页文字 | `读取 "h1" 到 标题` |
| 打印到日志 | `打印 标题` |
| 检查是否成功 | `断言 页面包含 "欢迎"` |

### 条件判断

```
如果 页面包含 "成功"
  截图 "成功.png"
否则
  截图 "失败.png"
结束
```

### 循环

```
重复 3 次
  点击 "#next"
  等待 1 秒
结束
```

## 常见问题

**Q: 双击 .hrpa 文件没反应？**
A: 先双击 `安装文件关联.bat` 安装文件关联（只需一次）。

**Q: 脚本报错找不到元素？**
A: 打开浏览器按 F12 查看元素，用右键「复制 → Copy selector」获取选择器。

**Q: 浏览器没打开？**
A: 确保电脑上有 Microsoft Edge 或 Google Chrome（Win10/11 自带 Edge）。

**Q: 怎么知道脚本跑没跑成功？**
A: 运行窗口标题会显示「✓ 运行成功」或「✗ 运行失败」，底部有详细日志。
